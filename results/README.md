# Results

This directory presents selected results from the MATLAB simulation and USRP/LabVIEW implementation of the Enhanced NCNP Detector for 5G Waveform Using Cognitive Radio During Disasters project.

## MATLAB Simulation Results

The MATLAB simulation evaluated spectrum-sensing performance through the following analyses:

- 5G QPSK signal generation
- QPSK signal reception
- QAM signal generation
- Probability of detection (Pd) and probability of false alarm (Pfa) for varying SNR
- Energy detection for varying SNR
- Comparison of noise-filtering approaches
- Receiver Operating Characteristic (ROC) curve
- Pd and Pfa evaluation for a Wiener-filtered signal

## Hardware / Experimental Results

The hardware-based implementation utilized:

- NI USRP-2901
- LabVIEW
- USRP receiver design and front-panel monitoring
- Carrier frequency of 5.5 GHz

## Interpretation

The MATLAB results were used to examine spectrum-sensing behavior under different signal and noise conditions, while the USRP/LabVIEW implementation provided a hardware-based spectrum-sensing demonstration. The evaluation measures included Pd, Pfa, energy detection, filtering performance, and ROC analysis.
