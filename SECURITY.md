# Security Policy

This repository is an academic research project and not an operational production system. The current materials do not indicate that the project has undergone formal security review or deployment hardening.

## Reporting a vulnerability

Please report potential security issues privately and do not disclose them publicly until they have been reviewed.

If GitHub private vulnerability reporting is enabled for this repository, use that workflow. Otherwise, contact the repository owner through the associated GitHub profile and include:

- a concise description of the issue
- affected files, commands, or implementation areas
- the steps required to reproduce the problem
- any suggested mitigation or remediation

## Expectations

- Do not open public issue threads for confirmed or suspected vulnerabilities before triage.
- Keep reports focused on the technical impact and reproduction details.
- Be prepared to provide additional context while the issue is reviewed.

## Current status

No confirmed security issues are documented in the available repository materials. This policy may be updated as the project evolves.
