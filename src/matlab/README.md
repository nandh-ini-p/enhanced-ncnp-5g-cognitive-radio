# MATLAB Simulation Assets

This directory is reserved for MATLAB-based simulation and analysis files for the enhanced NCNP detector.

## Intended content

The project README identifies the following MATLAB deliverables as part of the repository structure:

- `signal_generation.m` — QAM signal generation
- `ncnp_detector.m` — NCNP detector implementation
- `energy_detector.m` — energy detection algorithm
- `wiener_filter.m` — Wiener filter implementation
- `performance_analysis.m` — Pd/Pfa analysis
- `roc_analysis.m` — ROC generation
- `main_simulation.m` — main simulation driver

## Current status

This directory is a project skeleton. The actual MATLAB implementation files have not yet been added to the repository.
